# Campus Lunch

A lightweight, accessible, mobile-friendly webpage for students choosing campus lunch.

## Features
- Displays cafeteria meals with names, descriptions, prices in KRW, and vegetarian badges.
- Labeled Day Selector: filter between Monday, Tuesday, and Wednesday.
- Dynamic count updates (`3 meals available`).
- Clean minimalist styling: white background, black text, thin gray borders, keyboard focus accessibility.
- Zero dependencies: runs locally via `file://` or hosted on GitHub Pages without a backend server or build tool.

## Deployment to GitHub Pages
1. Push repository files (`index.html`, `style.css`, `app.js`, etc.) to your GitHub repository (e.g. `campus-lunch`).
2. Go to **Settings** > **Pages** in your GitHub repository.
3. Under **Branch**, select `main` (or `master`) and `/ (root)`, then click **Save**.
4. Access the site at `https://<your-username>.github.io/campus-lunch/`.
